# Türk Masalları Kütüphanesi - Etnik Ferman Koleksiyonu

Bu proje, Programlamaya Giriş dersi vize ödevi kapsamında hazırlanmış, Türk halk anlatı geleneğindeki masalları dijital ortamda estetik ve erişilebilir kılan tek sayfalık bir web uygulamasıdır.

## 📜 Proje Özeti
Proje; Keloğlan Masalları, Halk Hikayeleri ve Sihirli Masallar olmak üzere 3 farklı kategoride derlenmiş 8 adet Türk masalını dikey açılır ferman görünümünde sunmaktadır.

## 🛠️ Teknik Özellikler
- **Tek HTML Dosyası:** Bootstrap, jQuery veya başka bir dış kütüphane kullanılmadan; tamamen saf HTML, CSS ve JavaScript (Vanilla JS) ile yazılmıştır.
- **Çevrimdışı (Offline) Desteği:** Sayfa herhangi bir harici görsel klasörüne veya CDN bağlantısına ihtiyaç duymadan, internet bağlantısı kapalıyken bile tam performansla çalışır.
- **Dinamik Canlı Arama:** Başlık bazlı anlık arama algoritması içerir.
- **Kategori Filtreleme:** Masalları türlerine göre anında süzme imkanı sağlar.
- **Gece / Gündüz Çinisi Teması:** Türk çini sanatından esinlenilen Gece ve Gündüz modları arasında tek tıkla geçiş olanağı sunar.
- **Etkileşimsel Araçlar:** 
  - Okundu durumu takibi ve dinamik sayaç
  - Rastgele masal getirme (🎲)
  - Tek tıkla metin kopyalama (📋) ve doğrudan yazdırma (🖨️) desteği
  - Toplu ferman açma / kapatma kontrolleri

## 🚀 Çalıştırma
Proje tek bir dosyadan oluşmaktadır. `index.html` dosyasını herhangi bir güncel web tarayıcısında (Chrome, Edge, Firefox, Safari vb.) açarak doğrudan çalıştırabilirsiniz.
